Instructions

Upload a TSV (tab-separated values) file with the following format:

  • Header row: assessor pmid
  • Data rows: One row per abstract assignment
  • Example: alice 25763772

The system will automatically:

  • Find all annotations in each abstract
  • Filter to only include annotations where models disagree
  • Create assignment records for the specified assessor

Example TSV content:

assessor	pmid
alice	25763772
alice	25847295
bob	26316050
